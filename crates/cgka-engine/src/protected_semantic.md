This module owns the actual protected receiver, actual Engine send path and concrete NostrTransportAdapter. Original operation bytes, canonical packet bytes and request bytes remain distinct; JSON reserialization is not declared the original operation digest. Original card chunks and current configured group/operator policy are journaled before sending. Every exact encrypted outbound message is retained before publishing. Publication requires positive configured endpoint acknowledgments for every part; it does not establish human viewing. One 30-second deadline covers the whole card; an uncertain publish or timeout leaves HOLD and cannot retry or manufacture completion.

Candidate message provenance and original transport bytes remain in the same owned journal. Only the finite non-heart reaction vocabulary is supported; text replies and commands are not interpreted. Target correlation uses the exact owned application IDs after complete publication. One-use lookup selects an existing receipt with an exact original operation digest and rechecks configured operator policy, then fsyncs consumption before return.

No production external schema or authenticated public receipt import exists here.

These receipts are source evidence, never a deployment permission or host effect executor. Nonempty journal restart refuses.
